The renderer embeds subsets. Latin, Greek and Cyrillic are supported subject
to actual glyph checks. Missing glyphs and right-to-left scripts fail clearly
instead of changing evidence; use the authorized UTF-8 CSV/TXT output for those
inputs. This does not claim support for all Unicode scripts or PDF/UA conformance.
The fonts fill the existing sans-serif brand role; they are not Host Grotesk.
